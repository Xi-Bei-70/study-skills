# 双轨复习讲义与交互式截图卡片生成器 (Dual-Track HTML + SVG Notes)

本技能将课件 PDF、教材章节或已学课程内容，转化为**可 100% 替代原版 PPT、内嵌原生 SVG 矢量图、支持单卡筛选与一键纯净截图**的交互式学习讲义，并在聊天框同步交付完整 Markdown 全文。可独立用于任意学科，也可配合同级技能 [stem-study-tutor](../stem-study-tutor/SKILL.md)（模式 4D）联合使用。

---

## 一、 触发场景

1. 用户要求将课件、章节或错题整理成“可替代原版 PPT 的复习讲义 / 知识卡片”。
2. 用户需要同时拥有**浏览器可交互、适合高分辨率截图的 HTML 卡片**和**聊天框可检索复制的 Markdown 笔记**。
3. 需要通过手绘矢量图（状态转移图、二叉树、概率区间切分、韦恩图、系统框图、凸函数切线图等）直观掌握复杂概念。

---

## 二、 生成前的“强制全景复盘协议” (Pre-Note Retrospective Check)

动笔生成任何一批讲义（无论是 HTML 还是 Markdown）之前，**必须先在内部完整核对**：
1. 之前讲解过程中覆盖过的**每一句大白话直觉、公式零件拆解、纠偏过的课件笔误（Typo）以及补全的例题零跳步步骤**；
2. 对照原版课件或教材每一页的核心内容与插图，确保没有任何考点、性质证明思路或快捷秒杀公式被遗漏或缩水；
3. 检查全部数学公式、上下标、矩阵行列方向与算术数值的 100% 准确性；
4. **分批颗粒度控制**：内容较多时主动拆分为饱满批次（每批聚焦 **4~6 张高密度知识卡片 + 1~2 张母题/真题实战卡片**），宁可分批输出，绝不把整章几十页硬塞进缩水页面。

---

## 三、 双轨同步输出规范（每次回复必须同时包含轨道 A 与轨道 B）

### 轨道 A：生成并保存单文件 HTML 交互讲义卡片
- **生成前必读母本**：先读取 [assets/lecture-card-template.html](assets/lecture-card-template.html)，严格沿用其配色变量、KaTeX 配置、控制栏交互脚本与卡片布局结构；需要更多 SVG 绘图示例与结构细节时，读取 [references/workflow-and-examples.md](references/workflow-and-examples.md)。
- **文件保存**：将生成的完整单文件 `.html` 写入当前工作区（例如 `<章节名>_讲义卡片.html` 或 `Batch1_复习讲义.html`，或用户指定的输出路径），并在回复中附上可点击文件路径，方便用户直接在浏览器打开、筛选单卡并切换纯净截图模式。
- **视觉与交互标准**：
  1. 护眼学术风配色（纯白卡片 `#ffffff` + 浅灰底色 `#f1f5f9` + 深蓝主标题），顶部控制栏提供**全部/单卡筛选按钮**与 **`📸 切换纯净截图模式`**（支持按 `Esc` 退出截图模式）。
  2. 内嵌 **KaTeX 自动渲染**（确保行内 `$...$` 与块级 `$$...$$` 正确渲染）。
  3. **手绘原生 `<svg>` 矢量图**：涉及状态图、编码树、区间切分、系统框图、几何边界时手写精确 `<svg>`，附箭头 `marker` 与清晰中英标注。
  4. **每张知识卡片固定 4 大功能区**：
     - `📐 严谨数学定义与标准公式`（浅蓝区：中英术语对照 + 标准公式 + 符号零件表）
     - `🗣️ 学长大白话直通车 & 零跳步推导`（暖黄区：大白话直觉 + 小数字算例 + 隐藏跳步补全）
     - `⚡ 考场秒杀流水线 & ⚠️ 防坑雷达`（翠绿区：Step 1-2-3 套路 + 简单英文答题句型 + Typo 纠偏）
     - `📌 课堂趣味背景记忆锚点`（底部批注）
  5. **独立【🏆 母题与真题实战】卡片**：收录典型例题或用户提供的真题，给出破题导航与零跳步标准卷面解答。

### 轨道 B：聊天框同步输出 1:1 完整 Markdown 讲义
- **严禁只写“请打开 HTML 文件查看”**。必须在聊天回复中同步输出完整对应的 Markdown 讲义正文（含完整 LaTeX 公式、对齐的 ASCII 辅助图与零跳步推导），方便用户在聊天记录中直接搜索和复制。
