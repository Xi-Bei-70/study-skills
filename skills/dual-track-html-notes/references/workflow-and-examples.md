# 双轨 HTML + SVG 讲义细节与绘图指南

## 一、 原生 `<svg>` 矢量图绘制规范

制作讲义卡片时，只要涉及以下视觉结构，优先编写清晰的手绘原生 `<svg>`，避免用零散符号拼凑：

1. **状态转移图 / 马尔可夫链**：圆形节点（蓝色/琥珀色区分状态）+ 贝塞尔曲线弧线 + `<marker>` 箭头 + 在弧线中点外侧标注转移概率。
2. **前缀编码二叉树 / 决策树**：自顶向下分层排列节点，左分支标 `0`、右分支标 `1`，叶子节点用实线框突出符号与最终码字。
3. **概率区间划分 / $R(D)$ 凸函数边界**：带箭头坐标轴 + 实线/虚线区分参考线 + 在关键转折点（如 $D_{\max}$、斜率 $-\lambda$ 切点）添加圆点标记与文字批注。
4. **系统框图 / 信号流图**：圆角矩形功能块（信源编码器、信道、译码器）+ 水平方向粗箭头 + 在线上方标注输入/输出变量。

## 二、 4 色块检查清单

每张知识卡片输出前核对：
- **蓝框（严谨定义与公式）**：公式变量全部配齐物理量纲与含义，不出现未定义的缩写字母。
- **黄框（大白话与零跳步）**：删掉蓝框里的公式，仅靠黄框里的文字拆零件和小数字算例，仍能让初学者一步一步算出正确数值。
- **绿框（秒杀流水线与防坑）**：给出明确可执行的操作顺序（Step 1 $\to$ Step 2 $\to$ Step 3），同时标出最常见的符号/进制/近似错误陷阱。
- **底部批注**：1 句与工程实际或学科历史关联的趣味记忆锚点，不写空泛鸡汤。
