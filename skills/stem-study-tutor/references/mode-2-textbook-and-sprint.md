### 【2A 标准输出范例 1：《随机信号分析》课本第 63–65 页（平稳信号与具体数字翻译）】

### PDF 第 77–79 页（课本第 63–65 页）：§3.1.1 平稳随机过程的概念与广义平稳判据

#### 1. 本节核心干货一句话清底
- 在第 2 章里，一般随机信号在 $t=1\text{s}$ 和 $t=2\text{s}$ 的统计均值和相关性全都不一样，没法做频谱分析。
- 本节引入**平稳（Stationary）**，就是筛选出**“不管早上 8 点还是半夜 12 点去采样，统计脾气（均值与相关性）永远不变”**的乖巧信号（如熟睡心率、接收机热噪声），从而把二元自相关函数 $R_X(t_1, t_2)$ 降维成只跟时间差 $\tau = t_1 - t_2$ 有关的一元函数 $R_X(\tau)$。

#### 2. 核心定义与必考推导：主次分流与人话降维拆解

- 🟢 **【定义 3.1：严格平稳 (SSS)】—— 概念了解，高阶证明不考**
  - **课本核心式**：$f_X(x_1,\dots,x_n; t_1,\dots,t_n) = f_X(x_1,\dots,x_n; t_1+u,\dots,t_n+u)$。
  - **人话直觉**：不管你在时间轴上取多少个采样点，把这些采样点整体往左或往右平移任意 $u$ 秒，测出来的概率分布分毫不差。考试常考它与下面广义平稳（WSS）的一条选择题关系：**一般情况“严平稳 $\implies$ 宽平稳（反之不成立）”；唯独【高斯过程】下，“严平稳 $\iff$ 宽平稳（完全等价）”！**

- 🔴 **【定义 3.2：广义平稳 (WSS) 及为什么 $R(t_1,t_2)$ 变成了 $R(\tau)$】—— 必考核心！**
  - **课本核心式**：
    $$E[X(t)] = m(t) = m(t+u) = \text{常数}$$
    $$R(t_1, t_2) = R(t_1+u, t_2+u) = R(\tau, 0) = R(\tau), \quad \tau = t_1 - t_2$$
  - **为什么二元函数 $R(t_1, t_2)$ 突然变成了只跟差值 $\tau = t_1 - t_2$ 有关的 $R(\tau)$？用具体数字算给你看**：
    1. 假设你在 **$t_1 = 5\text{ 秒}$** 和 **$t_2 = 2\text{ 秒}$** 切两刀算相关性 $R(5, 2)$。注意这两个时刻**相隔了 $\tau = 5 - 2 = 3\text{ 秒}$**。
    2. 根据平稳性，把两个采样时刻同时加上平移量 $u$，相关性不变。为了消掉第二个位置的参数，我们故意选平移量 **$u = -2\text{ 秒}$**（即两个时刻同时减去 $2\text{ 秒}$）：

```text
  平移前时间轴:  0s ------- t2=2s ---------- t1=5s -----> t  (两时刻相隔 τ = 5 - 2 = 3s)
                 |           |                |
                 |  <--u=-2s-+       <--u=-2s-+  (整体向左平移 u = -t2 = -2s)
                 v                   v
  平移后时间轴: (t2+u)=0s ---------- (t1+u)=3s=τ --------> t  (起点被固定在0，终点正好就是差值τ!)
```

       - 第一个时刻变成：$t_1 + u = 5 - 2 = 3\text{ 秒}$（正好就是时间差 $\tau = 3$！）；
       - 第二个时刻变成：$t_2 + u = 2 - 2 = 0\text{ 秒}$（被钉死在原点 $0$！）；
       - 于是 $R(5, 2) = R(3, 0)$！同理，$R(103, 100)$ 同时减去 $100$ 也等于 $R(3, 0)$！
    3. **一句话结论**：只要两时刻相隔 $\tau$ 秒，令 $u = -t_2$，自相关永远等于 $R(t_1 - t_2, 0) = R(\tau, 0)$。把后面那个永远不变的 `, 0` 省掉不写，就成了只与时间差 $\tau = t_1 - t_2$ 有关的一元函数 **$R(\tau)$**！

#### 3. 📖 原书插图与物理直觉（课本第 64 页【图 3.1】）
- **图 3.1(a) 平稳过程**：多条样本曲线的中心均值是一条水平直线（均值恒定），且任意相隔 $\tau$ 的切片上下波动幅度一致。
- **图 3.1(b) 非平稳过程**：样本曲线随时间 $t$ 整体往上飘移或发散（均值和方差随 $t$ 改变）。

#### 4. 📝 原书内嵌例题零跳步全解（课本第 64–65 页【例 3.1】） & 应试考点标定
- **【考场判断广义平稳（WSS）的 2 条死规矩】**：
  1. **看均值 $E[X(t)]$**：化简后必须是**不含时间 $t$ 的常数**。
  2. **看自相关 $R(t_1, t_2)$**：化简后**只能含有时间差 $(t_1 - t_2)$（即 $\tau$）**，绝不能残留单个的 $t$ 或相加项 $(t_1 + t_2)$！
- **【📝 课本【例 3.1】零跳步带推】**：
  - **题干**：设随机相位正弦波 $X(t) = A\cos(\omega_0 t + \Theta)$，其中 $A, \omega_0$ 为常数，初相 $\Theta \sim U(0, 2\pi)$（概率密度 $f_\Theta(\theta) = \frac{1}{2\pi}$）。判断 $X(t)$ 是否广义平稳。
  - **Step 1（验均值）**：把 $\theta$ 从 $0$ 到 $2\pi$ 积分求平均：
    $$E[X(t)] = \int_0^{2\pi} A\cos(\omega_0 t + \theta)\frac{1}{2\pi} d\theta = 0 \quad (\text{余弦积满一个周期 } 2\pi \text{ 面积抵消为 } 0\text{，是常数，过第一关！})$$
  - **Step 2（验自相关 —— 补全书上省略的积化和差步骤）**：
    $$R(t_1, t_2) = E[A\cos(\omega_0 t_1 + \Theta) \cdot A\cos(\omega_0 t_2 + \Theta)]$$
    显式调用**三角积化和差母公式** $\mathbf{\cos\alpha\cos\beta = \frac{1}{2}[\cos(\alpha-\beta) + \cos(\alpha+\beta)]}$：
    - 相减项：$(\omega_0 t_1 + \Theta) - (\omega_0 t_2 + \Theta) = \omega_0(t_1 - t_2)$（随机变量 $\Theta$ 正好相减抵消！）；
    - 相加项：$(\omega_0 t_1 + \Theta) + (\omega_0 t_2 + \Theta) = \omega_0(t_1 + t_2) + 2\Theta$。
    代回期望式拆开：
    $$R(t_1, t_2) = \frac{A^2}{2}\cos\omega_0(t_1 - t_2) + \frac{A^2}{2}\underbrace{E[\cos(\omega_0(t_1 + t_2) + 2\Theta)]}_{\text{在 }(0,2\pi)\text{ 积满两个周期，恒为 }0} = \frac{A^2}{2}\cos\omega_0\tau$$
    结果只含时间差 $\tau = t_1 - t_2$（**过第二关**）$\implies$ **得证 $X(t)$ 是广义平稳过程！**
- **🔴 考场变式防坑**：如果考题把 $\Theta$ 改成在 $(0, \pi)$ 上均匀分布，第二步里的相加项积分就不再等于 $0$，会残留 $(t_1 + t_2)$，直接变成**非平稳**！

### 【2A 标准输出范例 2：《随机信号分析》课本第 66–68 页（循环平稳与分步钉死法）】

### PDF 第 80–82 页（课本第 66–68 页）：§3.1.2 循环平稳过程与“随机滑动抹平”定理（定理 3.2 & 3.3）

#### 1. 本节核心干货一句话清底
- **什么是循环平稳（Cyclostationary）？** 信号的均值和自相关虽然随时间变，但**每隔一个固定周期 $T$ 就原样重复一次**（如带周期载波的调制信号）。
- **课本第 67–68 页满屏公式的【定理 3.2 & 3.3】到底在干嘛？** 只干了一件事：**只要给一个“忽高忽低的周期循环信号 $X(t)$”加上一个在 $[0, T]$ 内均匀抽签的随机起点滑块 $\Theta$，新信号 $Y(t) = X(t - \Theta)$ 的波峰波谷就被彻底“抹平”成纯平稳信号了！**

#### 2. 课本推导主次分流与人话降维拆解
- 🟢 **【定理 3.2（第 67 页那串带 $y_1\dots y_n$ 的长公式证明）—— 非考点！直接略过推导】**
  - **为什么不用细看？** 前面一长串 $y_1\dots y_n$ 全是陪跑的背景板，它是在证“$n$ 维严格平稳”，考场不考这种多维下标证明。
  - **10 秒看懂它怎么证出来的（切瑞士卷原理）**：
    书上换元后积分区间变成了从 $-\tau$ 到 $T-\tau$。注意这个区间的总宽度 $(T-\tau) - (-\tau) = T$，**正好是整整一个周期 $T$**！既然里面的函数每隔 $T$ 就重复一圈，那不管你是从 $[-\tau, T-\tau]$ 下刀切一圈，还是从 $[0, T]$ 切一圈，切出来的总面积完全相等：
    ```text
    周期为 T 的波形:   ... /\  /\  /\  /\ ...
    从 [-τ, T-τ] 切一圈:   |---长度 T---|      --> 包含 1 个完整波峰 + 1 个完整波谷
    从 [ 0,   T ] 切一圈:     |---长度 T---|    --> 同样是 1 个完整波峰 + 1 个波谷！面积完全相等！
    ```
    所以积分上下限里的 $-\tau$ 直接被抹掉变回 $[0, T]$，证明结果跟平移量 $\tau$ 无关。翻篇！

- 🔴 **【定理 3.3（第 68 页：求抹平后的均值 $m_Y$ 与自相关 $R_Y(\tau)$）—— 必考计算结论！】**
  课本要算 $Y(t) = X(t - \Theta)$ 的均值 $m_Y = E[X(t - \Theta)]$。为什么书上突然写了个双层大括号 $E\{E[X(t-\Theta) \mid \Theta]\}$？
  - **人话动作拆解（“分步钉死法”——专门对付两个随机变量同时乱动）**：
    式子里有两个活物同时乱动：信号 $X$ 自己在随机抖动，滑块 $\Theta$ 也在 $[0, T]$ 里随机乱滑，没法一口气算平均，所以分两步走：
    1. **第一步（算里层 $E[X(t-\Theta) \mid \Theta]$ —— 先把滑块 $\Theta$ 用钉子钉死！）**：
       竖线 `| Θ` 的意思就是**“假装 $\Theta$ 现在已经抽完签了，是个固定死数字”**。既然 $\Theta$ 不动了，单算信号 $X$ 在 $(t-\Theta)$ 这一刻的均值，结果自然就是原来的均值函数 $m_X(t - \Theta)$。
    2. **第二步（算外层 $E\{\dots\}$ —— 拔掉钉子，让滑块 $\Theta$ 在 $[0, T]$ 滑一圈求平均！）**：
       因为滑块 $\Theta$ 在 $[0, T]$ 上均匀分布（概率密度是 $\frac{1}{T}$），外层期望就是把刚才的结果从 $0$ 到 $T$ 积分再除以 $T$：
       $$m_Y = \frac{1}{T}\int_0^T m_X(t - \theta) d\theta = \frac{1}{T}\int_0^T m_X(u) du \quad (\text{常数！})$$
  - **🔥 考场直接默写的最终秒杀公式（把原来的周期均值和自相关在 1 个周期 $T$ 内积分除以 $T$ 抹平即可）**：
    $$m_Y = \frac{1}{T}\int_0^T m_X(t) dt, \qquad R_Y(\tau) = \frac{1}{T}\int_0^T R_X(t+\tau, t) dt$$

### 【2B 标准输出范例 1：《信号与系统》模块化串讲】

### Module 1 (Page 1-4)：线性时不变系统（LTI）与卷积积分

**1. 模块范围与核心中英对照**
- Linear Time-Invariant (LTI) Systems (线性时不变系统)
- Convolution Integral (卷积积分)
- Impulse Response (冲激响应)

**2. 重点原文精准翻译**
A continuous-time system is completely characterized by its impulse response if it is linear and time-invariant. -> 如果一个连续时间系统是线性和时不变的，那么它完全由其冲激响应所表征。

**3. 核心机制白话解析**
LTI 系统的核心在于“叠加性”与“时移性”。任意输入信号都可以看作是无数个不同时刻、不同强度的冲激信号的集合。因为系统是时不变的，输入延迟多少，输出就延迟多少；因为系统是线性的，总输出就是所有单独冲激响应的加权求和。这个加权求和的连续时间数学表达就是卷积积分。

**4. 🔴 必考点与做题指南**
- **题型预测**：必考大题。给定系统冲激响应 $h(t)$ 和输入信号 $x(t)$，要求通过图解法或解析法计算输出 $y(t)$。
- **避坑指南**：图解法求卷积时，必须严格按照“反转 (翻折) - 平移 - 相乘 - 积分”四个步骤进行。特别注意积分区间的边界条件，分段积分时极易因区间判断失误导致错误。
- **公式规范**：连续时间卷积积分公式为：
  $$y(t) = \int_{-\infty}^{\infty} x(\tau)h(t-\tau) d\tau$$

### 【2B 标准输出范例 2：《通信网络》模块化串讲】

### Module 1 (Page 1-4)：TCP 连接控制与三次握手

**1. 模块范围与核心中英对照**
- Connection Establishment (连接建立)
- Sequence Number (序列号)
- ACK (Acknowledgment / 确认应答)

**2. 重点原文精准翻译**
Client sends a SYN segment specifying the port number of the server and the client's initial sequence number. -> 客户端发送一个 SYN 报文段，指明服务器的端口号以及客户端的初始序列号。

**3. 核心机制白话解析**
TCP 三次握手的核心目的是在不可靠的网络层上建立可靠的端到端连接。第一步客户端发送 SYN 报文请求建立连接并同步初始序列号；第二步服务端回复 SYN+ACK 报文，确认客户端的请求，并同步自己的初始序列号；第三步客户端发送 ACK 报文，确认服务端的序列号。经过这三个步骤，双方的发送和接收能力均被验证，连接正式建立。

**4. 🔴 必考点与做题指南**
- **题型预测**：必考简答题或画图题。要求准确画出三次握手时序图。
- **避坑指南**：注意第二次握手时，SYN 和 ACK 标志位必须同时为 1。计算消耗的序列号时，SYN 报文段本身消耗一个序列号，因此后续的 ACK 确认号通常为接收到的序列号加 1。
