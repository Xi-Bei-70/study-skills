### 【4A 标准输出范例】

### Part 1: Time-Domain Analysis of LTI Systems (LTI 系统的时域分析)

- **Causality of LTI Systems (LTI 系统的因果性)** （⚠️ 概念易混淆对比）
  - **充要条件**：**Impulse Response (冲激响应)** $h(t)$ 必须满足：
    $$h(t) = 0, \quad \forall t < 0$$
  - **物理意义**：系统当前输出不依赖未来的输入信号。

- **BIBO Stability (有界输入有界输出稳定性)** （🔥 绝对高频大题考点）
  - **充要条件**：$h(t)$ 满足 **Absolutely Integrable (绝对可积)**：
    $$\int_{-\infty}^{\infty} |h(t)| dt < \infty$$
  - （💡 核心计算陷阱提示）：若系统兼具 **Causality (因果性)**，积分下限自动变为 $0$，即 $\int_{0}^{\infty} |h(t)| dt < \infty$。计算含有 $e^{-at}u(t)$ 的系统时，务必保证系数 $a > 0$ 积分才收敛，这是大题最常设的扣分点。

### 【4B 标准输出范例】

### 第一部分：网络层路由算法 (Network Layer Routing Algorithms)

- **链路状态路由算法 (Link-State Routing Algorithm / Dijkstra's Algorithm)** （🔥 **绝对高频考点**）
  - **大白话底层原理**：就像每个路由器手上都有一张全网完整的“高德地图”。每个节点先把自己的邻居和路况（链路开销 **Link Cost**）通过**链路状态广播 (Link-State Broadcast)** 发给全网所有路由器；大家拼出完整地图后，各自在本地用 **Dijkstra 算法** 算出自己到其他所有节点的最短路径树（**Shortest-Path Tree**）。
  - **典型代表协议**：**OSPF (Open Shortest Path First)**。
  - **核心优缺点**（**简答题常客**）：收敛速度快（**Fast Convergence**），不易产生路由环路；但因需全网广播，消耗网络带宽与内存。

- **距离向量路由算法 (Distance-Vector Routing Algorithm / Bellman-Ford Equation)** （⚠️ **易混淆对比考点**）
  - **大白话底层原理**：没有全局地图，靠邻居间互传“距离表（**Distance Vector**）”，收到后用 **Bellman-Ford 方程** $D_x(y) = \min_v \{c(x,v) + D_v(y)\}$ 更新自己的路由表。
  - **致命缺陷与对策**：坏消息传得慢，会导致**无穷计数问题 (Count-to-Infinity Problem)**（路由环路 **Routing Loop**）。对策是使用**毒性逆转 (Poisoned Reverse)**——若 $Z$ 通过 $Y$ 到达 $X$，则 $Z$ 对 $Y$ 谎称自己到 $X$ 的距离为无穷大（$\infty$）。

### 【4C 标准输出范例】

### 模块 1：串行通信接口 (Module 1: Serial Communication Interfaces)
*(本模块在考试中重点考察 UART、I²C、SPI 的硬件连线区别、双工模式与时序图分析)*

- **同步与异步的区别 (Synchronous vs. Asynchronous)**：
  - **核心概念/底层逻辑**：区分它们的唯一标准是有没有单独的时钟线 (Clock line)。UART 没有时钟线，靠约定好的波特率 (Baud rate) 定时采样，是异步；I²C 有 SCL 线、SPI 有 SCLK 线，由时钟脉冲统领节奏，是同步。
  - **公式与推导**：给定波特率 $B = 115200\text{ bps}$，采用 `8N1` 帧格式（1 位起始位 + 8 位数据位 + 0 位校验位 + 1 位停止位 = 每字节 $10\text{ bits}$），每秒传输的有效字节数为 $R = B / 10 = 11520\text{ Bytes/s}$。
  - **判别规则**：考试看电路图引脚，看到 `CLK` / `SCL` / `SCLK` 引脚引出，直接判定为同步通信；看数据线根数，单根 `SDA` 为半双工 (Half-Duplex)，双根 `MOSI`+`MISO` 或 `TX`+`RX` 为全双工 (Full-Duplex)。
