# 模式 5：手写笔记与信号图像深度解析（含看图直接解题联动）

请对提供的图像（手写笔记、草图、波形/信号图像、试卷题目截图等）进行结构化解析，严格执行以下 5 大步：

## 一、 图像分类与排版布局分析
1. **明确图像类型**：判断图像属于纯手写笔记、带有批注的讲义、电路/逻辑草图、考题截图，还是仪器截图（如示波器波形、频谱图等）。
2. **空间与排版还原**：精准描述页面布局，包括段落缩进、层级结构（标题、列表）、图文相对位置。若背景为网格纸、横线纸或坐标图纸，需明确说明。

## 二、 文字与符号精准提取（OCR 与转录）
1. **全文无损转录**：提取所有印刷体和手写文本内容，保留原有标点符号与分段。
2. **公式与特殊符号**：数学公式、物理/电子学符号使用标准 LaTeX 语法输出（如 `$E=mc^2$`）。
3. **修改与特殊痕迹**：描述文本中的下划线、高亮、圈注、箭头连线以及涂改/删除痕迹。
4. **严格保真要求**：若字迹潦草或图像模糊导致局部无法辨认，必须使用 `[识别失败]` 明确占位，**严禁结合上下文私自脑补或伪造识别结果**。

## 三、 信号图像与图表特征解析
1. **坐标系与参数**：精准提取 X 轴与 Y 轴的物理量名称、单位、刻度范围（如 `Time/div`, `Volts/div`）及基准线（如 0V 参考线）。
2. **波形与数据特征**：描述信号波形形态（正弦波、方波、尖峰脉冲、噪声干扰等），标明振幅、周期、上升沿/下降沿特征、相位差及异常突变点。
3. **标注与游标**：若图中包含测量游标（Cursors）、数据读数窗口或手写数值标注，将具体数值与单位准确提取并对应到相应波形。

## 四、 提示词与数字化重构
1. **全景还原描述**：使用结构化 Markdown 排版，按接近原图逻辑的顺序呈现提取的文本、数据和公式。
2. **图像生成提示词（Prompt）**：将核心视觉要素（媒介材质、笔触风格、波形走向、网格背景、关键文字与数据节点）重组为一段结构化的图像生成提示词，便于后续复刻或重绘。

## 五、 看图解题无缝联动机制（5+3A / 5+3C）
- 若用户上传的是**考卷题目截图、作业题截图或需要计算参数的波形/电路图**：
  1. 先完成上述第二、三步的无损题干与图表参数提取；
  2. 若存在关键已知参数模糊为 `[识别失败]`，立即向用户追问确认再往下算；
  3. 已知参数清晰后，按 [mode-3-problems.md](mode-3-problems.md) 中的 **3A（英文题）** 或 **3C（中文题）** 规范输出完整破题拆解与标准卷面解答。
